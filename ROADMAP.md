# Roadmap

A rough order, not a fixed calendar: repeat or split a topic whenever it needs more time. Java follows the same idea as JavaScript where it can, so each concept is seen twice in one day.

## JS for DSA (10-day track)

Before Phase 4, [`js-for-dsa/`](js-for-dsa) covers the JavaScript basics DSA needs, with an animated lesson each day: numbers and digits → loops and counting steps → functions → arrays → two pointers → strings → objects as hash maps → `Map` and `Set` → sorting and sliding window → 2D arrays, recursion and binary search. The advanced JavaScript in Phase 3 comes after it.

## Phase 1: Programming basics (both languages)

| Day | JavaScript | Java |
|-----|-----------|------|
| 1 ✅ | if / else, comparison, `%` | Hello World, types, if / else |
| 2 ✅ | for loops: count, sum, build arrays | for loops, arrays, for-each |
| 3 ✅ | functions, `return`, return types | methods, return types, integer division |
| 4 | while loops, nested loops, star patterns | while loops, nested loops, star patterns |
| 5 | strings: indexing, methods, palindrome | `String`, `charAt`, `StringBuilder` |
| 6 | arrays: search, min/max, reverse, remove | arrays: same problems, fixed size |
| 7 | objects: keys, values, looping over objects | 2D arrays (grids, matrices) |
| 8 | practice day: mixed problems | practice day: mixed problems |

## Phase 2: Intermediate

| JavaScript | Java |
|-----------|------|
| array methods: `map`, `filter`, `reduce`, `find`, `sort` | classes and objects |
| arrow functions, scope, `let` vs `const` vs `var` | constructors, `this`, encapsulation (private + getters) |
| destructuring, spread `...`, rest parameters | `static` vs instance members |
| callbacks and higher-order functions | inheritance, `super`, method overriding |
| closures | polymorphism, abstract classes, interfaces |
| recursion | recursion |
| error handling: `try / catch / throw` | exceptions: checked vs unchecked |

## Phase 3: Advanced JavaScript and Java collections

| JavaScript | Java |
|-----------|------|
| classes, `extends`, getters / setters | `ArrayList` |
| `Map` and `Set` | `HashMap` and `HashSet` |
| promises and `async / await` | generics |
| modules (`import / export`) | `Comparable` / `Comparator`, sorting objects |
| the event loop | streams and lambdas |

## Phase 4: DSA (mostly Java, some JavaScript)

Big-O thinking → linear and binary search → sorting (bubble, selection, insertion, merge) → two pointers and sliding window → hashing → stacks and queues → linked lists → trees and BST → recursion and backtracking → graphs (BFS, DFS) → simple dynamic programming.

## Phase 5: Web development (JavaScript)

HTML and CSS basics → the DOM (select, change, create elements) → events → forms and validation → `fetch` and JSON → `localStorage` → a small project each week (to-do list, quiz app, weather app) → then React.

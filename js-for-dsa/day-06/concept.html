Strings

A string is a row of characters you can read but never change. To get a different string, you build a new one.

← Day 5Day 7 →

1. Reading a string like an array

const s = "cat";
s.length;           // 3
s[0];               // "c"
s[s.length - 1];    // "t"
s[10];              // undefined (out of range, like arrays)

for (const ch of s) {
  console.log(ch);  // "c", then "a", then "t"
}

Use for...of when you only need the characters. Use a normal for loop when you also need the index i.

2. Strings are immutable

"Immutable" means it can't be changed. Writing into a string does nothing:

let s = "cat";
s[0] = "b";        // silently ignored
s;                 // still "cat"

s = "b" + s.slice(1);   // build a NEW string instead
s;                      // "bat"

Need to edit in place? Turn it into an array with s.split(""), change the array, then glue it back with .join("").

Letters "a" to "z" have the codes 97 to 122, in order. Digits "0" to "9" are 48 to 57. That's why "a" < "b" is true, and why c >= "0" && c <= "9" tests for a digit.

4. Predict the output

Say the answer out loud first, then reveal.

"hello"[1]

"e". Indexes start at 0, just like arrays.

"abc".split("")

["a", "b", "c"]. Splitting on the empty string gives one character per slot.

"Zebra" < "apple"

true! Capital letters (65 to 90) come before lower case letters (97 to 122). Lower-case both sides first if case shouldn't matter.

"5" + 3 and "5" - 3

"53" and 2. + with a string glues; - turns the string into a number. Keep numbers and strings apart.

String.fromCharCode("y".charCodeAt(0) + 2)

"{", not "a". Codes don't wrap around by themselves. To wrap, use % 26 on the position 0 to 25 (Q8).

strings are arrays you can't edit

Everything you learned on Days 4 and 5 works on strings: linear scans, left/right pointers for palindromes, and run counting. The one difference is that s[i] = x never works.

const arr = s.split("");   // O(n): now you can swap
// ... two pointers, swaps ...
const t = arr.join("");    // O(n): back to a string

Watch out for hidden costs: slice, split, join and toLowerCase each walk the whole string, so they are O(n). Call them once, before the loop, not inside it.

Numbers, operators and digits

1. The arithmetic operators

**power2 ** 532

JavaScript has no integer division. To get "how many whole times does 2 fit in 7", divide and drop the decimals:

Math.floor(7 / 2);   // 3
Math.trunc(-7 / 2);  // -3  (trunc cuts toward 0; floor would give -4)

2. Predict the output

Say the answer out loud first, then reveal.

17 % 5

2. 5 fits into 17 three times (15), and 2 is left over.

8 % 2 === 0

true. A remainder of 0 means "divides exactly", so this is how you test for even numbers.

472 % 10 and Math.floor(472 / 10)

2 and 47. The first reads the last digit and the second removes it. Remember this pair: it's the whole lesson.

5 == "5" vs 5 === "5"

true vs false. == converts the string to a number first. Always use ===.

0.1 + 0.2 === 0.3

false! Decimals are stored approximately (0.30000000000000004). Stick to whole numbers when you can.

4. Building a number: rev * 10 + digit

Going the other way, multiplying by 10 makes room for a new last digit:

let rev = 0;
rev = rev * 10 + 2;   // 2
rev = rev * 10 + 7;   // 27
rev = rev * 10 + 4;   // 274

Combine this with the loop above and you can reverse a number (Q5).

5. Special values you will use in DSA

Infinity > 1e300;     // true: start with this when looking for a minimum
-Infinity;            // start with this when looking for a maximum
Number.isInteger(4);  // true
Number.isInteger(4.5);// false
Math.abs(-7);         // 7
Math.max(3, 9, 2);    // 9

Why Infinity? If you start a minimum at 0, an array like [5, 8] would wrongly say 0 is the minimum. Infinity loses to every real number.

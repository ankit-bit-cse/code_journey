10-day track

JavaScript for DSA

Just enough JavaScript, understood deeply, to start solving data-structure and algorithm problems. Advanced JS (classes, promises, async) comes later.

How each day works

  1. Concept (≈15 min): open the day's animated lesson below. Press Play on every animation and answer the "predict the output" cards before revealing them.
  2. Questions (≈25 min): solve js-for-dsa/day-NN/questions.js in order. Each question has Steps comments; try without them first.
  3. Check (≈5 min): ./check.sh 1 for Day 1, ./check.sh 2 for Day 2, and so on. Then commit and push.

  • Day 2Loops and counting stepsfor, while, break, continue, nested loops · O(n), O(n²), O(√n)
  • Day 3Functions, scope and helpersarrow functions, defaults, pure functions, passing functions, the call stack
  • Day 4Arrays: traversal and linear searchindexing, push/pop vs shift, references vs copies, prefix sums
  • Day 5Arrays in place: swap and two pointersmutating in place, both-ends pointers, read/write pointers, merging
  • Day 6Stringsimmutability, slice, split/join, char codes, building strings
  • Day 7Objects as hash mapsfrequency counting, key in obj, Object.entries, two-sum
  • Day 8Map and SetO(1) lookups, deduplication, sliding window with a Set
  • Day 9Sorting, array methods and sliding windowmap / filter / reduce, the sort gotcha, comparators, fixed windows
  • Day 102D arrays, recursion and binary searchgrids, base cases and the call stack, lo / mid / hi

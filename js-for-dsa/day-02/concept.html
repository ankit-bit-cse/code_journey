Loops and counting steps

A loop repeats a few lines. Learn to follow it round by round, and to count how many rounds it takes.

← Day 1Day 3 →

1. Two kinds of loop

Use for when you know how many rounds you want. It has three parts: where to start, when to keep going, and what to do after each round.

for (let i = 1; i <= 3; i++) {
  console.log(i);   // 1, then 2, then 3
}

Use while when you loop until something happens and you don't know the count in advance:

let n = 40;
while (n > 1) {
  n = Math.floor(n / 2);   // 20, 10, 5, 2, 1
}

Watch out: if the condition never becomes false, the loop never ends. Make sure something inside the loop moves you toward the exit.

2. The accumulator pattern

Most loop questions follow the same three-part shape: make a variable before the loop, update it inside, use it after.

let sum = 0;            // before: the "empty" answer
for (let i = 1; i <= 4; i++) {
  sum += i;             // inside: 1, 3, 6, 10
}
console.log(sum);       // after: 10

Pick the right starting value: 0 for a sum, 1 for a product, "" for a string, [] for a list.

4. break and continue

continue skips the rest of this round and jumps to the next one. break leaves the loop completely.

for (let i = 1; i <= 10; i++) {
  if (i % 3 === 0) continue;   // skip 3, 6, 9
  if (i > 7) break;            // stop for good at 8
  console.log(i);              // 1, 2, 4, 5, 7
}

A variable made with let inside the for (...) disappears when the loop ends. If you need its value after a break, declare it before the loop:

let i;
for (i = 2; i < 100; i++) {
  if (i * i > 50) break;
}
console.log(i);   // 8, the first i with i * i > 50

5. Predict the output

Trace each loop on paper first: one row per round, one column per variable. Then reveal.

let s = 0; for (let i = 0; i < 5; i++) s += 2; then s

10. The body runs 5 times (i = 0, 1, 2, 3, 4) and adds 2 each time. i < 5 stops before 5.

let c = 0; for (let i = 1; i <= 10; i++) { if (i % 2 === 0) continue; c++; } then c

5. The even rounds are skipped, so only i = 1, 3, 5, 7, 9 reach c++.

let n = 100, r = 0; while (n > 0) { n -= 30; r++; } then r

4. n goes 70, 40, 10, -20. After the 4th round n is no longer > 0.

How many times does x++ run? for (i = 0; i < 4; i++) for (j = 0; j < 3; j++) x++;

12. The inner loop runs fully (3 times) for each of the 4 outer rounds: 4 × 3.

let p = 1; for (let i = 1; i <= 4; i++) p *= i; then p

24. 1 × 1 × 2 × 3 × 4. If you had started p at 0 the answer would be 0 forever.

6. Nested loops: visiting every pair

Put a loop inside a loop and the inner one runs completely for each round of the outer one. Starting j at i + 1 means each pair is visited once, and never a box with itself.

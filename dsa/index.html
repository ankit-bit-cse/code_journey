After JS for DSA

DSA in JavaScript

Data structures and algorithms, one topic at a time, in five phases. Every day: an animated lesson, 8 scaffolded questions and ./check.sh dsa N.

← JS for DSA

How each day works

  1. Concept (≈15 min): open the day's lesson. Play every animation and answer the "predict the output" cards before revealing them. Teaching together? Press Teach mode.
  2. Questions (≈25 min): solve dsa/day-NN/questions.js in order. The Steps get shorter as the day goes on: by Q8 you only get the pattern and a hint.
  3. Check (≈5 min): ./check.sh dsa 1 for Day 1, ./check.sh dsa 2 for Day 2, and so on. Then commit and push.

2. Phase 2 · Array and string patterns (coming next)

Prefix sums and Kadane · advanced two pointers (3-sum, container with most water) · variable sliding window · hashing patterns (group anagrams, subarray sum = k) · string problems.

3. Phase 3 · Linear data structures

Just-enough JS classes · linked lists (reverse, fast and slow pointers, cycles, merging) · stacks (valid parentheses, monotonic stack) · queues and deques.

4. Phase 4 · Trees and graphs

Binary trees and traversals · binary search trees · heaps and priority queues · backtracking · graphs (BFS, DFS, islands, topological sort, Dijkstra).

5. Phase 5 · Problem-solving techniques

Greedy (intervals, jump game) · dynamic programming (1D, then 2D: grid paths, LCS, knapsack) · bonus: bits, tries, union-find.
